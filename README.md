# Personal Budgeting App

## Project Goal

The goal of this project is to create a free personal budgeting app that helps users keep track of their spending without requiring a paid subscription. Many budgeting apps put useful features behind subscriptions, so this project aims to provide a free alternative for users to manage their expenses and monthly budgets.

## MVP Scope

1. **Add Expenses:** Allow users to enter expenses with a name, amount, category, and date. Expenses will be saved to a CSV file so they can be accessed later.
2. **Set Monthly Budget:** Allow users to enter a monthly spending limit and save it for the future.
3. **Calculate Remaining Budget:** Calculate the total expenses for the current month and subtract that amount from the monthly budget to display how much money remains.

The application will use a command-line interface with a menu that allows users to select between these features.

## Future Plans

If possible, I would like to expand the application with additional features:

- **Monthly Spending Summaries:** Show users a summary of their spending over a month.
- **Category Breakdowns:** Display how much users spend in different expense categories.
- **Edit Expenses:** Allow users to modify expenses they have already entered.
- **Compare Monthly Spending:** Allow users to compare their spending across different months.

## Tech Stack

- **Programming Language:** Java
- **Libraries:** Java standard library, including `ArrayList`, `LocalDate`, `FileWriter`, `BufferedReader`, and `Scanner`.
- **Data Storage:** CSV files will store expenses and monthly budget information.
- **Development Environment:** IntelliJ IDEA
- **Version Control:** Git and GitHub
